# User Roles

## Student

Students consume learning content, practice questions, mock tests, AI help, exemplar resources where allowed, and view progress.

Access depends on the resolved subscription/feature authorization state of the account/child.

## Parent

Parents manage child profiles, view progress, manage subscriptions, receive notifications, and understand learning outcomes.

Parent must not access another parent’s child data.

## Teacher

Teachers manage assigned students only. Teacher capabilities include:

- Add students within plan limit
- Invite students
- Manage classrooms
- View learning signals where available
- Create/complete/dismiss tasks
- Add private notes
- Communicate with linked parents where available
- Reset passwords and email credentials under plan rules

Teachers cannot access unassigned students.

## Admin

Admins manage platform operations and support:

- Users and families
- Access and subscriptions
- Parent-child and teacher-student association
- Offers and influencers
- AI/settings
- Operations Dashboard
- Analytics
- Bulk tools
- Support tools
- View-as user read-only simulation

Admin-only endpoints must use server-side authorization.
