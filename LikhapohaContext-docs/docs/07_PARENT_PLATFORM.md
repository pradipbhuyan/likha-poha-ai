# Parent Platform

## Vision

The Parent Dashboard should help parents understand their child’s progress clearly and quickly.

## Core Capabilities

- Manage child profile(s)
- View current plan and platform access state
- See progress summaries
- Understand weak/strong areas
- View homework and exam insights
- Receive notifications
- Upgrade subscription when needed

## Parent Rules

- New parent starts on Free Tier.
- Free access is restricted.
- Paid plans unlock full platform access.
- Family Premium supports two child profiles.
- Parent must not access unrelated child data.

## Roadmap

- richer progress analytics
- weekly/monthly reports
- homework/exam center
- subscription expiry reminders
- teacher communication summaries
- milestone notifications
