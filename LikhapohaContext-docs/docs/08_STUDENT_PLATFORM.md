# Student Platform

## Vision

The Student Experience should motivate learning and make the next best action obvious.

## Core Dashboard

- Continue Learning
- Today’s Goals
- Recent Activity
- Recommended Lessons
- Mock Test Summary
- Weak Topic Practice
- Access/upgrade state where needed

## Motivation

Future motivation tools:

- streaks
- achievements
- XP/points
- completion celebrations
- personalized goals

## Access Rules

Student features must follow the feature matrix. Free users must not access premium-only exemplar or unrestricted mock tests.

## Roadmap

- personalized recommendations
- adaptive learning path
- topic mastery
- mock test improvement charts
- achievements/streaks
