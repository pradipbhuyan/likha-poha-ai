Core Theorems
Remainder Theorem
medium Polynomials 🔥 Popular
p(a) = remainder when p(x) ÷ (x − a)
If p(x) is divided by (x − a), the remainder equals p(a). No long division needed.
📖 What this formula means
The Remainder Theorem states: if you divide polynomial p(x) by (x − a), the remainder is p(a). Substitute x = a directly — no division needed.
🔤 Variables & Symbols
p(x)The polynomial being divided
aValue from divisor: if (x − a), substitute x = a
p(a)The remainder after division
🎯 When to use
Use when divisor is a linear expression (x − a) or (x + a). Never use for quadratic or higher-degree divisors.
✏️ Step-by-step solved example
Find the remainder when p(x) = x³ + 2x − 5 is divided by (x − 2)
1Identify a from divisor: (x − 2) → a = 2
2Write p(2) = (2)³ + 2(2) − 5
3Evaluate: = 8 + 4 − 5
4Remainder = 7 ✓
⚠️ Common mistakes
✗(x + 2) means substitute x = −2, NOT x = +2 — sign flip!
✗p(a) = 0 means it's a factor, not just any remainder
✗Theorem only works for linear divisors (x − a)
💡 Memory tip
"Look inside the bracket. (x − 5) → plug in 5. (x + 3) → plug in −3. The sign flips! Remainder = p(that value)."

Factor Theorem
medium Polynomials
(x − a) is a factor of p(x) iff p(a) = 0
A special case of Remainder Theorem. If p(a) = 0, then (x − a) divides p(x) exactly.
