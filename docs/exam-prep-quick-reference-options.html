⚠️ Common Exam Traps
Deceleration → a is negative. Check sign convention before substituting.
Projectile horizontal velocity is CONSTANT — no acceleration acts horizontally.
🎯 Last-minute Points
At max height: v_y = 0, v_x unchanged
Max range → θ = 45° · Max height → θ = 90°
Relative velocity: v_AB = v_A − v_B (vector subtraction)

★ Recommendation: Option A — 4th Permanent Tab

The 4th tab pattern is the most discoverable and reusable. Students can switch between Structured Learning → Quick Reference → Practice → back to Reference without losing their place. Phase 2 links directly to it. Content is organized by exam × subject, renders instantly (no API), and can be expanded with more topics over time.

If the header feels too crowded: combine Options A + B — the 4th tab is the primary route, but Phase 2 in Structured Learning also expands a compact inline preview as a secondary shortcut.
