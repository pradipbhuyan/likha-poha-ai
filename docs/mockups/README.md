# Likha Poha AI Reel Mockups

Static promotional mockups are organized by role:

- `student/index.html` - student dashboard, lessons, Ask Doubt, SOF mock test, and progress screens.
- `parent/index.html` - parent dashboard, child progress, AI suggestions, visual aids, and voice narration screens.
- `teacher/index.html` - teacher dashboard, roster, student progress, notes, and school/independent teacher screens.
- `admin/index.html` - learning ops, RAG upload, context review, visual aid, and voice narration screens.

Open `docs/mockups/index.html` in a browser to browse all sets. The frames are designed in a 9:16 format for reels and shorts.
- `codebase/index.html` - six route-driven product-tour screens derived from the actual frontend pages.
- `ppt-journey/index.html` - PowerPoint-friendly light and dark 16:9 journey mockups for parent, student, and teacher flows.
- `ppt-ask-mock/index.html` - focused PowerPoint slides for Ask Doubt and CBSE/SOF mock tests across chapters.
- `ppt-journey-pricing/index.html` - full journey deck plus proposed pricing and India competitor comparison slides.
